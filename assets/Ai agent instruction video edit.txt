  CHECK: the notes cover every preset A–J in brief 3.4 with at least one reference

STEP 2 — Word-level timing  [brief 2, 9]
  2.1 Extract audio: `ffmpeg -i main.mp4 -vn -ac 1 -ar 16000 /data/media/audio/asr.wav`
      and a full-quality copy (48 kHz) for the mix.
  2.2 faster-whisper (language "bn", word_timestamps=True) → data/asr_words.json.
      Background job if slow (Section 9).
  2.3 Align SCRIPT words (brief Section 9, split on spaces; keep punctuation attached
      to its word) to ASR words with sequence alignment (e.g. difflib/Needleman–Wunsch on
      normalized text; interpolate unmatched words inside their phrase). Output
      data/words.json: [{i, text, start, end, phrase_id}], text = script spelling.
  CHECK: word count = script word count; times strictly increasing; every word inside
  one of the measured speech phrases in brief 2 (±0.3 s); first word ≈ 0.5 s, last
  word ends ≈ 67.4 s. Write a small timing table to scripts/logs/timing_check.log.

STEP 3 — Shot plan data  [brief 7, 8, 10]
  3.1 Transcribe brief Section 8 into data/shots.json, one object per shot:
      {id, start, end, words:[i...], heroes:[{i, colour B|C|W|gradient, size, preset}],
       support_preset, layer (front|behind per word), reframe {scale, x, y, cut|push},
       ui:[UI-n], effects:[outline_echo, bend, flip, glitch...], sfx:[...]}.
      Snap all start/end times to words.json (brief times are ±0.5 s estimates).
  3.2 Validation script: every word belongs to exactly one shot; heroes match brief
      Section 8; density/rhythm rules of brief 10 (average shot 1.5–2.0 s, about

      face-coverage rule from brief 10.
  CHECK: validation passes; print a shot table to scripts/logs/shotplan.log.

STEP 4 — Picture prep  [brief 1, 3.5, 3.6]
  4.1 Crop the pillarbox (data/crop.json) → /data/media/work/cropped.mp4 at 30 fps

  4.2 AI upscale to a working master (ideal 2160x3840, minimum 1080x1920), chunked and

  4.3 Grade per brief 3.6 (dark, moody, cinematic; tame the bright glass wall and
      white shirt; deeper shadows; warm accents; vignette) as an ffmpeg filter chain or
      .cube LUT stored in data/grade.json / assets/. Light sharpen + 2–3% grain at the
      end of the pipeline, not here, if grain is done in Remotion.
  CHECK: output/preview/grade_before_after_XX.jpg (3 timestamps) next to reference

  7. HOW TO VERIFY WITHOUT WATCHING OR HEARING
==========================================================================================

- Stills: `ffmpeg -ss <t> -i file.mp4 -frames:v 1 -q:v 3 out.jpg` (Remotion:
  `npx remotion still`). View them with your image-viewing tool.
- Strips/contact sheets: ffmpeg `tile` filter or Python PIL. Label every tile with
  timecode.
- Side-by-side vs reference: hstack your frame and the reference target (scaled to the
  same height). Compare: hero size vs support size ratio, overlap amount, masking,
  blur streak length, letter spacing, darkness of the grade.
- Timing: compare words.json with the frame where each word's opacity first > 0.
- Audio: `ffmpeg -i x.wav -af ebur128=peak=true -f null -` and loudnorm print_format=json.
- Never mark a check as passed without a saved evidence file or log line.

11.1  scripts/checkpoint.sh
---------------------------
Protects against: secrets, files > 50 MB, RAW MEDIA in the repo, oversized previews,
parallel pushes (flock), committing mid-rebase, hidden rebase conflicts, half-written
files (auto mode).

#!/usr/bin/env bash
# Usage (manual):  ./scripts/checkpoint.sh "wip(3.2): form validation half done"
# Usage (auto):    AUTO=1 ./scripts/checkpoint.sh "auto: checkpoint"
# Exit codes: 0 ok/nothing to do, 1 blocked (secret/big file/bad state),
#             2 push failed, 3 rebase conflict (aborted), 4 lock busy
set -uo pipefail
cd "$(git rev-parse --show-toplevel)" || exit 1
MSG="${1:-wip: checkpoint}"
AUTO="${AUTO:-0}"
BRANCH="$(git symbolic-ref --short HEAD 2>/dev/null || echo main)"
GITDIR="$(git rev-parse --git-dir)"

# 0) LOCK: only one checkpoint at a time.
#    Auto mode: skip this round if busy. Manual mode: wait up to 120s.
exec 9>/tmp/checkpoint.lock
if [ "$AUTO" = "1" ]; then
  flock -n 9 || { echo "ℹ️ Another checkpoint is running. Skipped."; exit 0; }
else
  flock -w 120 9 || { echo "❌ Lock busy for 120s. Try again."; exit 4; }
fi

# 0b) Refuse to run in the middle of a rebase / merge / other git operation
if [ -d "$GITDIR/rebase-merge" ] || [ -d "$GITDIR/rebase-apply" ] || \
   [ -f "$GITDIR/MERGE_HEAD" ] || [ -f "$GITDIR/index.lock" ]; then
  echo "❌ Git is in the middle of a rebase/merge (or index.lock exists). Not committing."
  echo "   Fix it first (see section 8.4). Auto-push stays paused until then."
  [ "$AUTO" = "1" ] && exit 0 || exit 1
fi

# 0c) Auto mode only: skip if files are still being written (changed in last 30s)
if [ "$AUTO" = "1" ]; then
  RECENT="$(find . -path ./.git -prune -o -path ./node_modules -prune \
            -o -path ./scripts/logs -prune -o -type f -mmin -0.5 -print -quit)"
  if [ -n "$RECENT" ]; then
    echo "ℹ️ Files changed in the last 30s (e.g. $RECENT). Skipped this round."
    exit 0
  fi
fi

git add -A

# 1) Block known secret patterns in staged changes
PATTERNS='ghp_[A-Za-z0-9]{30,}|github_pat_[A-Za-z0-9_]{20,}|gh[ousr]_[A-Za-z0-9]{30,}|sk-[A-Za-z0-9_-]{20,}|AKIA[0-9A-Z]{16}|xox[baprs]-[A-Za-z0-9-]{10,}|-----BEGIN [A-Z ]*PRIVATE KEY-----'
if git diff --cached -U0 | grep -E "^\+" | grep -Eq "$PATTERNS"; then
  echo "❌ SECRET PATTERN FOUND in staged changes. Commit blocked."
  git diff --cached --name-only
  git reset -q
  exit 1
fi

# 2) Block the actual stored token value, if one exists
if [ -f ~/.git-credentials ]; then
  TOK="$(sed -n 's#https://[^:]*:\([^@]*\)@.*#\1#p' ~/.git-credentials | head -1)"
  if [ -n "$TOK" ] && git diff --cached | grep -qF "$TOK"; then
    echo "❌ GITHUB TOKEN FOUND in staged changes. Commit blocked."
    git reset -q
    exit 1
  fi
fi

# 3) Block files over 50 MB
BIG="$(git diff --cached --name-only --diff-filter=AM | while read -r f; do
  [ -f "$f" ] && [ "$(stat -c%s "$f")" -gt 52428800 ] && echo "$f"; done)"
if [ -n "$BIG" ]; then
  echo "❌ Files over 50 MB (add them to .gitignore or compress them):"; echo "$BIG"
  git reset -q
  exit 1
fi

# 3b) VIDEO PROJECT: block raw media anywhere except small proxies/previews
MEDIA="$(git diff --cached --name-only --diff-filter=AM | grep -Ei '\.(mp4|mov|mkv|avi|webm|mxf|prores|wav|aif|aiff|flac|exr|tif|tiff)$' \
  | grep -Ev '^(output/proxy/|output/preview/|assets/sfx/)' || true)"
if [ -n "$MEDIA" ]; then
  echo "❌ Raw media staged (keep it in /data/media, not in the repo):"; echo "$MEDIA"
  git reset -q
  exit 1
fi
SMALLMAX=26214400   # proxies/previews/sfx must stay under 25 MB each
BIG2="$(git diff --cached --name-only --diff-filter=AM | grep -E '^(output/proxy/|output/preview/|assets/sfx/)' | while read -r f; do
  [ -f "$f" ] && [ "$(stat -c%s "$f")" -gt $SMALLMAX ] && echo "$f"; done)"
if [ -n "$BIG2" ]; then
  echo "❌ Proxy/preview/sfx file over 25 MB (re-encode smaller):"; echo "$BIG2"
  git reset -q
  exit 1
fi

# 4) Commit (skip if nothing changed)
if git diff --cached --quiet; then
  [ "$AUTO" = "1" ] && [ -z "$(git log "origin/$BRANCH..HEAD" --oneline 2>/dev/null)" ] \
    && { echo "ℹ️ Nothing to commit or push."; exit 0; }
  echo "ℹ️ Nothing new to commit. Pushing any unpushed commits."
else
  git commit -q -m "$MSG"
fi

# 5) Sync + push. Conflicts are NEVER hidden: abort the rebase and report.
for i in 1 2 3; do
  if git ls-remote --exit-code --heads origin "$BRANCH" >/dev/null 2>&1; then
    if ! git pull -q --rebase origin "$BRANCH"; then
      if [ -d "$GITDIR/rebase-merge" ] || [ -d "$GITDIR/rebase-apply" ]; then
        git rebase --abort
        echo "❌ REBASE CONFLICT with origin/$BRANCH. Rebase aborted."
        echo "   Your commit is safe locally: $(git log -1 --oneline)"
        echo "   Tell the user. Do NOT force-push. See section 8.4."
        exit 3
      fi
      echo "Pull failed (try $i/3, probably network). Retrying in 5s..."; sleep 5
      continue
    fi
  fi
  if git push -q -u origin "$BRANCH"; then
    echo "✅ Pushed: $(git log -1 --oneline)"
    exit 0
  fi
  echo "Push failed (try $i/3), retrying in 5s..."; sleep 5
done
echo "❌ PUSH FAILED after 3 tries. Work is committed locally. Tell the user."
exit 2

Then run:  chmod +x scripts/checkpoint.sh
If `flock` is missing, install util-linux or tell the user. Don't remove the lock.

11.3  scripts/autopush.sh  (background safety net, every 4 minutes)
------------------------------------------------------------------
#!/usr/bin/env bash
# Background auto-push every 4 minutes. Stop it with:  kill "$(cat /tmp/autopush.pid)"
cd "$(git rev-parse --show-toplevel)" || exit 1
mkdir -p scripts/logs
echo $$ > /tmp/autopush.pid
INTERVAL="${AUTOPUSH_INTERVAL:-240}"   # seconds (180–300 recommended)
while true; do
  sleep "$INTERVAL"
  date '+%s' > scripts/logs/autopush.heartbeat
  AUTO=1 ./scripts/checkpoint.sh "auto: checkpoint $(date '+%H:%M')" \
    >> scripts/logs/autopush.log 2>&1
  # keep the log small
  tail -n 200 scripts/logs/autopush.log > scripts/logs/autopush.tmp && \
    mv scripts/logs/autopush.tmp scripts/logs/autopush.log
done

Then run:
    chmod +x scripts/autopush.sh
    mkdir -p scripts/logs
    if ! { [ -f /tmp/autopush.pid ] && kill -0 "$(cat /tmp/autopush.pid)" 2>/dev/null; }; then
      nohup ./scripts/autopush.sh >/dev/null 2>&1 &
    fi
Every ~5 manual pushes, check it is alive (same bash call as a checkpoint):
    if [ -f /tmp/autopush.pid ] && kill -0 "$(cat /tmp/autopush.pid)" 2>/dev/null; then
      echo "auto-push: running"; tail -n 3 scripts/logs/autopush.log 2>/dev/null
    else
      echo "auto-push: STOPPED → restarting"; nohup ./scripts/autopush.sh >/dev/null 2>&1 &
    fi
The loop saves files, NOT notes. Still update PROGRESS.md and push manually.

11.4  If the checkpoint fails
-----------------------------
  1. Exit 3 = rebase conflict. Rebase was aborted, commit is safe locally. Log it in
     Problems, TELL THE USER, keep working locally. Never resolve big conflicts by
     guessing. If the user asks: git pull --rebase origin <BRANCH>, fix files (keep both
     when unsure), git add -A && git rebase --continue, checkpoint "fix: merge conflict".
  2. "Middle of a rebase/merge" → git status; git rebase --abort (or merge --abort);
     stale .git/index.lock with no git running → rm -f .git/index.lock.
  3. Exit 1 "Raw media staged" / "over 50 MB" → add the file to .gitignore or move it
     to /data/media; for proxies re-encode smaller.
  4. 401/403 → token wrong/expired/no write access. Tell the user. Never print it.
  5. Network error → retry once, then ask the user to enable internet.
  6. Exit 4 = lock busy → check for a stuck git process, retry.
  7. Never use --force.
